## Содержание проекта

### Практическая работа №1 — Арифметические калькуляторы
Каталог: `practical_1_calculators/`

Реализованы четыре варианта калькулятора:
1. Последовательная реализация — выполнение операций в рамках последовательного сценария.
2. Функциональная реализация — отдельные функции для арифметических операций.
3. Реализация с циклом — повторное выполнение вычислений с помощью универсальной функции и цикла.
4. Объектно-ориентированная реализация — калькулятор в виде класса.

### Практическая работа №2 — Обработка строк
Каталог: `practical_2_strings/`

Программа представляет собой интерактивный тренажёр из пяти уровней:
- изменение регистра символов;
- поиск, замена и подсчёт вхождений подстрок;
- разделение и объединение строк с помощью `split()` и `join()`;
- проверки и преобразования строк;
- нормализация текста в редакторе.


### Практическая работа №3 — Текстовый лабиринт
Каталог: `practical_3_maze/`

Реализована текстовая игра с исследованием лабиринта. В ней предусмотрены:
- перемещение и исследование карты;
- поиск ключа и достижение выхода;
- сундуки, предметы и инвентарь;
- монстры, ловушки и портал;
- здоровье игрока;
- сортировка, поиск, удаление и применение предметов;
- демонстрация поверхностного и глубокого копирования объектов.

### Практическая работа №4 — Анализ данных Titanic
Каталог: `practical_4_titanic/`

Файл `analyze.py` выполняет анализ набора данных `titanic.csv` с использованием библиотек **Pandas** и **NumPy**.

Основные этапы анализа:
1. Загрузка CSV-файла и первичный просмотр данных.
2. Вывод размера таблицы, названий столбцов и типов данных.
3. Разделение признаков на числовые и категориальные.
4. Расчёт описательной статистики, среднего и медианного значений.
5. Подсчёт пропусков и их доли по столбцам.
6. Заполнение пропущенных значений возраста медианой.
7. Очистка данных от строк с отсутствующим портом посадки и, при большом количестве пропусков, удаление столбца `Cabin`.
8. Анализ выживаемости в целом, по полу и по возрастным группам.
9. Фильтрация пассажиров по заданным условиям.
10. Группировка данных по классу, полу и порту отправления.
11. Сохранение очищенного набора и сводного отчёта в CSV-файлы с последующей проверкой повторного чтения.

Исходный файл `titanic.csv` используется как входной набор данных. При запуске анализа создаются файлы `titanic_cleaned.csv` и `class_gender_report.csv`.

- Для практической работы №4 необходимы библиотеки:

## Установка зависимостей

Из корневого каталога проекта выполните:

```bash
python -m pip install -r requirements.txt
```

## Запуск работ

Перейдите в каталог нужной практической работы и запустите соответствующий Python-файл.

Примеры:

```bash
python sequential.py
python string_lab.py
python game.py
python analyze.py
```

Для четвёртой практической работы запускайте `analyze.py` из каталога `practical_4_titanic`, чтобы программа корректно нашла расположенный рядом файл `titanic.csv`.
