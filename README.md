# Практические работы по Python — самостоятельная реализация

В проекте сохранены четыре исходных учебных задания, но программы написаны заново: изменены архитектура, имена сущностей, алгоритмы организации меню, обработка ошибок и представление результатов.

## Состав
1. `practical_1_calculators` — один арифметический калькулятор, реализованный четырьмя способами: последовательный сценарий, функции операций, универсальная функция с циклом, класс.
2. `practical_2_strings` — интерактивный тренажёр из пяти уровней: изменение регистра; поиск/замена/подсчёт подстрок; `split` и `join`; проверки и преобразования строк; нормализация текста в редакторе.
3. `practical_3_maze` — текстовый лабиринт: исследование карты, ключ и выход, сундуки, монстры, ловушки, портал, здоровье, инвентарь, сортировка/поиск/удаление/применение предметов и демонстрация поверхностной и глубокой копии.
4. `practical_4_titanic` — анализ предоставленного CSV через Pandas и NumPy: изучение таблицы, пропуски, заполнение медианой, фильтрация, группировки и сохранение результатов.

## Запуск
Python 3.10 или новее. Для четвёртой работы:
`pip install -r requirements.txt`

Запускать скрипты из каталога соответствующей практической работы, чтобы относительный путь к CSV был корректным.

## Примечание
Датасет Titanic оставлен исходным, поскольку он является входными данными задания. Все `.py` файлы являются новой реализацией, а не копией исходных скриптов.
